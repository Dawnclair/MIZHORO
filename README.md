Программа МИЖОРО это приложение для моделирования искуственной жизни ограниченного роста с системой отлова.
Программа предназначена для среднего и крупного хозяйства, а также биологических исследований, обеспечивает облегчение расчётов численности популяции на определённом отрезке времени путём симуляции.
Вы устанавливаете программу, запускаете её и вводите необходимые данные. На основе формулы программа проводит симуляцию, строит график изменения численности и подводит итоги, уведомляет о состоянии популяции.
